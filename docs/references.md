# Third-party asset references

External assets copied into this repository are recorded here. Dependency
licenses remain governed by `go.mod` and `frontend/package.json`.

## Brand icons

`internal/stackrd/handlers/web/components/canvas/icons.templ` embeds unmodified
GitHub and Traefik SVG paths from
[Simple Icons](https://github.com/simple-icons/simple-icons). Simple Icons is
CC0, but the marks remain subject to their owners' trademark policies.

- **GitHub Invertocat:** identifies GitHub App connections. Source and usage
  guidance: <https://github.com/logos>.
- **Traefik Proxy:** identifies the Traefik proxy managed by Stackr. Source:
  <https://traefik.io/traefik>.

PostgreSQL uses Stackr's generic database icon rather than a brand mark.

## Project-drawn icons

The S3 bucket and generic canvas icons were drawn for this repository and do
not copy vendor logos.
